# План реализации: WordPress Custom Pinterest Share Plugin

## План верификации

### Ручное тестирование
1. Активировать плагин в WordPress.
2. Перейти на страницу одиночной записи (single post).
3. Навести курсор на изображение > проверить появление кнопки.
4. Кликнуть «Pin it» > проверить открытие модального окна с превью изображения.
5. Переключить тип ссылки на "Custom URL", ввести тестовый адрес.
6. Заполнить Title и Description, нажать «Pin it» > проверить, что открывается окно Pinterest с правильно склеенными параметрами.
